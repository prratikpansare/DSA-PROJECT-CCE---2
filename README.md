# Food-Delivery-Order-Queue-using-Linked-List

## Problem Statement

To design and implement a C++ based Food Delivery Order Management System using a Queue implemented with a Linked List. The system manages food orders using the FIFO (First In First Out) principle.

## Objective

To implement a Queue using a Linked List for managing food delivery orders and performing basic queue operations.

## Data Structure Used

- Queue
- Singly Linked List

## Operations

1. Place Order
2. Deliver Order
3. Display Pending Orders
4. View Next Order
5. Exit

## Concepts Used

- C++
- Queue
- Linked List
- Classes and Objects
- Pointers
- Dynamic Memory Allocation
- FIFO (First In First Out)

## Algorithm

1. Start the program.
2. Create an empty queue using a linked list.
3. Add a new food order at the rear of the queue.
4. Deliver the order from the front of the queue.
5. Display all pending orders.
6. Display the next order to be delivered.
7. Repeat the operations until the user selects Exit.
8. Stop the program.

## Advantages

1. Orders are processed in FIFO order.
2. Memory is allocated dynamically as new orders are added.
3. The queue can grow as needed, subject to available memory.
4. Customers' pending orders can be displayed easily.

## Conclusion

The Food Delivery Order Queue Management System demonstrates the implementation of a Queue using a Singly Linked List in C++. It performs essential operations such as placing orders, delivering orders, displaying pending orders, and viewing the next order. This project helps in understanding FIFO principles, pointers, classes, and dynamic memory allocation.
