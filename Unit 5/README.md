# Represent Web Pages and Hyperlinks Using a Directed Graph and Apply DFS

## Project Description

This project represents web pages and hyperlinks using a directed
graph in C++. Each web page is represented as a vertex, and each
hyperlink is represented as a directed edge.

Depth First Search (DFS) is used to explore all reachable web pages
from a selected starting page.

## Features

- Represent web pages using a directed graph
- Add hyperlinks between pages
- Select a starting web page
- Explore reachable pages using DFS
- Avoid visiting the same page repeatedly

## Technologies Used

- Programming Language: C++
- Data Structure: Directed Graph
- Graph Representation: Adjacency List
- Algorithm: Depth First Search (DFS)
- Concepts: Vectors, Recursion and Classes

## How to Run

Compile the program:

g++ WebPageDFS.cpp -o WebPageDFS

Run on Linux or macOS:

./WebPageDFS

On Windows:

WebPageDFS.exe

## Applications

- Web page navigation
- Graph traversal
- Network exploration
- Link analysis

## Conclusion

This project demonstrates how a directed graph and DFS algorithm
can be used to explore web pages reachable from a selected page.
